# 发布-v0.0.1

> 最后更新:2026-10-28

## 摘要

Matrix-Core v0.0.1 是第一个可独立运行的单会话核心服务：`matrix-core serve` 支持 WS（本地 token + Origin 白名单）与 `--stdio` 行分隔帧，完成一轮完整生命周期（流式 assistant/reasoning、工具、审批 allow/deny/timeout/allow-session、提问多选/自定义、abort、stats、`/clear`、`--resume`）。协议 v1.1 已冻结（6 文件 lock + fixtures/reducer/guards）；core 由 neo 移植 + `SessionHost`/`ProtocolIO` 组合，带 seq/epoch、durable transcript、崩溃半轮修复与单写者锁（与 mailbox `.alive` 互认）。发布闸门：48 tests / 0 fail（protocol+unit+guards+stdio/WS e2e），`verify.sh` ALL GREEN；commit `2e7257e`，tag `v0.0.1`。

## 交付范围

- **core**：`src/core/session-host.ts`（组合根 / seq·epoch / transcript / resume / 审批提问 / 命令子集 / 锁）、`protocol-io.ts`（AgentIO→协议事件）、移植模块（agent/tools/memory/wiki/mailbox/env/skills/session/checkpoint/shell…）。
- **serve**：WS/stdio、dispatch、本地 token、`/health`、`main.ts` 的 serve/status/stop/doctor。
- **协议**：v1.1，capabilities 实际 6 项；错误码含 `question_expired/slow_consumer/unsupported`；事件体内不带 seq。
- **测试**：48 pass / 0 fail / 12 文件；含 WS、锁双开、allow-session、SIGTERM mid-turn（reason=shutdown）、resume 幂等、transcript 尾部修复、旧会话 degraded。
- **文档**：PRD/架构/协议/计划/验收/release notes/simplify 清单 + 证据。

## 已知限制（v0.0.1）

- 单会话（Hub/多会话 v0.0.2）。
- 审批无断线宽限 / `no_client` / 滑动 deadline；allow-session 仅按工具名（write/edit），**无 cwd/路径校验（PathPolicy 未交付）**。
- WS 无合批/背压；`transcript.replay`/`peers`/`output.get`/`checkpoint.*`/`session.export`/附件未交付。
- 快照暂由 host 复用 protocol reducer 生成（目标在 serve）；core/ui 兼容层待清理。
- 详细清单见 `docs/v0.0.1-simplify.md` 与 release notes。
