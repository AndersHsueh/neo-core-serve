# 发布-v0.0.2

> 最后更新:2026-10-29

## 摘要

Matrix-Core v0.0.2 把单会话核心扩到可用形态：**PathPolicy 全量接入**（文件工具/refs/checkpoint，覆盖悬空 symlink 与边界负样本）；完成 **paths/命令注册表/帧解码** 三处统一并加 delta 快路径；WS 增加 **16ms/4KB/64 帧合批、背压 4408、transcript.fetch**；新增 **本地多会话 Hub + 每会话 worker**（session.*、并发 attach/owner/close/cwd 语义）；支持**图片附件**（严格 base64/magic、≤5 张/总 8MB、$ref/hydrate）。协议 v1.2 冻结（7 文件 lock）；`commands.json` 由注册表生成并由 docs:check 校验。测试 92 pass / 0 fail；功能提交 `0eca093`，最终 tag `v0.0.2` → `47bd5ef`（含发布后文档校正）。未接 CLI。

## 交付

- **PathPolicy**：`resolveRead/resolveWrite`（realpath + symlink 本体 + cwd 边界；悬空 symlink 写入拒绝）；工具/refs/checkpoint 接入。
- **统一**：`core/paths.ts`（sessions/transcripts/run/locks/token/runFile，NEO_* 覆盖）、`core/commands/registry.ts` 单表（18 命令 + aliases + mutates，HELP/未知命令/轮中保护派生）、`serve/frames.ts`、delta 快路径（只改当前 block）。
- **WS 合批/背压**：EventBatcher（16ms/4KB/64 帧、同 block delta 合并、512 帧/8MB 上限丢 ephemeral/4408）、`getBufferedAmount` 高水位。
- **transcript.fetch**：fromSeq 含、limit 200/1000、nextSeq；未知 session → `not_found`。
- **Hub**：`matrix-core hub`；每会话 worker（stdio）；session.list/create/attach/detach/close/rename；未 attach conflict；并发 attach 恰一成功；close 仅 owner 且 await worker≤2s；再次 attach 用会话 meta.cwd resume。
- **附件图片**：`turn.send.attachments`；严格 base64/magic/mime；≤5 张、单张 5MB、总 8MB；落 `sessions/attachments/<id>/`、`$ref`/hydrate。
- **配置**：`~/.neo/settings.json` 回落（GUI 联调）；Hub 未 attach 的 settings.get 直接读 defaultCwd 配置。

## 已知限制

- Hub 无空闲回收/自动重启、单客户端/会话；attach 仍总快照（增量用 transcript.fetch）。
- 历史轮次附件无协议元数据（刷新后不可回放）；附件仅 base64/8MB 帧；refs ≤5/200KB。
- 快照仍由 host 复用 reducer；`core/ui` 兼容层待清；PathPolicy 写入 TOCTOU 留 v0.0.3。
- 未接 CLI（C5 另立）。
