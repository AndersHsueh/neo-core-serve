## 2. 本版已修清单（v0.0.2 收尾，含文件）

1. **PathPolicy 悬空 symlink**（`src/core/path.ts`）。
2. **Hub 正确性**：overflow owner 清理、并发 attach（inflight + owner 先占）、close owner/await、worker cwd 用会话 meta、worker exit 用 lastSeq + identity（`src/hub/server.ts`）。
3. **Hub 性能/健壮**：sessions mtime 缓存 + 并行、worker 分离 decoder/超时/进程泄漏、大行缓冲 indexOf（`src/hub/{server,worker}.ts`）。
4. **Batcher**：merge 字节记账、ws/hub 高水位 4408（`src/serve/{batcher,ws}.ts`）。
5. **too_large 统一**：`frames.tooLargeResult()` + 提取请求 id，三处传输共用（`src/serve/frames.ts` + stdio/ws/hub）——**po 冒烟发现「回帧 id=?」后修复**，现有 e2e 覆盖（超长帧 id 一致、连接不被打断）。
6. **auth/paths**：`serve/auth.ts` 委托 `core/paths.ts`；hub 复用 `user`；capabilities 去重。
7. **协议 v1.2 + 命令目录**：`commands:gen` 生成 `protocol/commands.json`，`docs:check` 校验 registry↔json（24 条）。
