## 3. Core 接口（Lead 的 serve 依赖）

`src/core/session-host.ts` 导出 `createSessionHost(opts)`，返回：

```ts
interface SessionHost {
  readonly sessionId: string;
  readonly epoch: string;
  readonly seq: number;
  meta(): SessionMeta;                       // protocol 类型
  configView(): SettingsView;                 // 掩码
  usage(): { records: UsageRecord[]; totals: Usage };
  snapshot(): SessionSnapshot;                // blocks 由 transcript/messages 重建
  live(): SessionSnapshot["live"];
  send(text: string, refs: unknown, clientId: string): Promise<{ turnId: string }>;
  abort(turnId?: string): Promise<{ aborted: boolean }>;
  resolveApproval(blockId: string, decision: "allow"|"deny"|"allow-session"): boolean;
  answerQuestion(blockId: string, keys: string[], custom?: string): boolean;
  runCommand(name: string, args: string[]): Promise<CommandOutcome>;
  rename(title: string): void;
  close(): Promise<void>;
  onEvent(cb: (event: SessionEvent) => void): () => void;   // event 已含 seq/epoch
}
```

- 事件类型用 `import type` 从 `../../protocol/types.ts`（允许 type-only；运行时不依赖 protocol）。
- seq：只有 durable 事件递增；ephemeral 用当前 seq。epoch：启动生成，transcript header 持久化。
- 持久化：`~/.neo/sessions/<id>.json` + `transcripts/<id>.ndjson`（durable 事件逐行）；启动时 `--resume` 恢复；崩溃尾部修复（至少补 `turn.aborted`）。
- 审批：ProtocolIO 生成 blockId，发 `approval.request`，`resolveApproval` 解开；超时（默认 120s，测试可注入）→ `approval.resolve{by:"timeout"}` 并拒绝。
- 提问：`ask_user` 走 `question.request` / `answerQuestion`；超时取消。
- 命令子集：`help clear compact context cost tier fast balanced deep default mode tools history why auto provider model settings? rename usage?`；其余返回 `{ok:false,error}`。结果块 `CommandBlock`（text/markdown/kv/list）。
- 兼容 `-p` 语义：`send` 返回 turn 结果；错误通过 `stats.error`/`error` 事件。
